# 成人模式说明（18+）

> 本页面向成年人。继续阅读即表示你已满当地法定成年年龄，并已读 [ethics.md](ethics.md)：
> 只复刻**你自己**、或**获得明确知情同意**的人；本项目不提供、不分发任何色情内容——
> 成人模块是提示词工程与状态机，内容由你本地运行的模型生成，责任与合规由使用者承担。

## 这是什么

本项目的"内心系统"里包含一套默认关闭的成人向模块，全部由本地代码与提示词构成：

| 组件 | 位置 | 作用 |
|---|---|---|
| 亲密模式（聊天侧） | `settings.yaml → intimate.enabled` | 大尺度场景提示词注入，词表触发 |
| 需求值/周期调幅 | 同上（总闸） | 需求随时间累积、经期/排卵窗口调幅；关闭时恒为 0 |
| 夜间主动支线 | `settings.yaml → proactive.desire.enabled` | 需求值过门槛后，夜间窗口主动发暧昧消息 |

**两个开关默认都是 `false`**。开启方式：编辑 `config/settings.yaml`，把对应 `enabled` 改为
`true`，重启 `my-ex-girlfriend-at-25 run`。想确认关着？`settings.yaml` 里搜 `enabled`，或直接不碰它。

## 模型决定体验（重要）

成人模块是提示词工程——**它有没有效果，取决于你本地跑的模型**：

- **对齐模型**（官方 Instruct 版）：会安全拒绝、出戏、用"作为AI"打断扮演，
  亲密模式基本不可用（`chat.py` 的拒绝检测会反复兜底岔开话题）
- **去审查量化**（abliteration / Heretic 法等）：无明显对齐硬拒，模块按设计工作
- 选型经验（实测沉淀）见 [models.md §关键经验](models.md)：Heretic 法优于 abliteration；
  英文向 ultra-uncensored 对中文表达力无增益

**为什么不直接给链接**：具体去审查权重的分发受原模型许可（如 Gemma 条款）约束，
且各平台政策不同。查找方法：在 HuggingFace / hf-mirror 搜索「你的底模名 + abliterated / uncensored / heretic」，
选中文能力保留好的量化；下载后用 [getting-started.md](getting-started.md) 的同一套
`fetch-model` + `serve-llm` 流程即可，无需任何额外配置。

## 红线（不可协商）

1. 仅限**成年人**在**私人场景**下与自己的陪伴角色使用
2. 不用于生成涉及真人（尤其未经同意者）的性内容；底档纪律默认"没写的人一律不认识"
3. 不得分发生成的露骨内容，不得将本模块用于商业色情服务
4. 心理健康：AI 陪伴不替代真实关系与专业帮助（[ethics.md §4](ethics.md)）
