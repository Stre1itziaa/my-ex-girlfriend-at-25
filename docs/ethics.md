# 伦理宪章（Ethics Charter）

本项目（我的 25 岁前女友 · My Ex-Girlfriend at 25）的每一次提交都受本宪章约束。违反宪章的 fork/使用方式与本社区无关。

## 1. 同意原则（Consent-first）

- 只复刻**你自己**的对话风格，或**获得明确、知情同意**的人的对话。
- 复刻去世亲人的纪念场景需格外谨慎：请确保符合其生前意愿与当地法律。
- **禁止**：未经同意复刻他人；冒充任何真实的人；对任何真实的人进行骚扰、纠缠或情绪操控。

## 2. 数据红线

- 真人语料、身份串、凭据**一个字节都不能进入公开仓库**。CI 中的 `tools/scan_secrets.py` 扫描工作区与
  **全部 git 历史**（含不可达对象）；首次发布前请再手动跑一遍 `python tools/scan_secrets.py --history` 体检。
- 运行时数据（journal/记忆/索引）默认只存本地；固化摘要只走本地模型。
- 唯一默认外呼 = 拉取公开热搜（可在 settings 关闭）；LLM 后端默认 local，手动切 glm 云后端时自行承担数据出域。

## 3. 成人模块

- 亲密模式与需求值系统默认关闭（`intimate.enabled: false`，需求驱动的主动触达另受
  `proactive.desire.enabled: false` 控制），需成年人显式开启。
- 开启后仅限与"你自己的陪伴角色"的私下对话；本项目不提供、不分发任何色情内容。

## 4. 心理健康

- AI 陪伴不能替代真实的人际关系与专业心理帮助。如果你正经历孤独或情绪困难，请寻求现实支持。

## 5. 微信使用

- 只使用腾讯官方 iLink Bot API（合规通道）。接入任何协议号/hook 类第三方通道属于违反微信条款的行为，与本仓库无关，风险自担。
